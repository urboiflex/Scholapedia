# E-Learning System

This is a simple E-Learning web application built using the **ASP.NET Framework**.  
The system is designed to support online learning activities such as course management, user enrollment, and content delivery.

## Features
- User registration and login
- Course listing and enrollment
- Content management for instructors
- Basic progress tracking

## Technologies Used
- ASP.NET Framework (Web Forms or MVC)
- SQL Server (for database)
- HTML/CSS/JavaScript

## Getting Started
1. Clone the repository
2. Open the solution in Visual Studio
3. Configure the database connection in `web.config`
4. Run the project
